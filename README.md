# gyomu-connection-test

業務アプリ（個人用）の技術検証ページ。個人のMicrosoftアカウントでサインインし、
OneDriveのアプリ専用フォルダに小さなテスト用ファイルを読み書きできるかを確かめる。

- サインイン: [MSAL Browser](https://github.com/AzureAD/microsoft-authentication-library-for-js) 5.24.0（`vendor/`、MIT License）
- 公開ページ: https://kengookawa.github.io/gyomu-connection-test/
- 実データは置かない
